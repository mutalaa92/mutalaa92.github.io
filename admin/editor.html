✍️ نیا مضمون

یہاں مضمون لکھیں۔ Text Area کو محدود اور مرکزی چوڑائی میں رکھا گیا ہے تاکہ طویل تحریر پڑھنے اور لکھنے میں آسانی رہے۔

جس عبارت کا فونٹ، رنگ یا سائز تبدیل کرنا ہو اسے پہلے منتخب کریں۔ اس طرح ایک ہی مضمون میں عربی اور اردو الگ الگ فونٹ میں رہیں گی۔

تصویر منتخب کرکے Editor میں شامل کی جا سکتی ہے۔ مستقل GitHub تصویر اپلوڈ کے لیے cPanel کا محفوظ upload endpoint الگ سے درکار ہوگا۔

یہ پاس ورڈ صرف اس براؤزر کے موجودہ فارم میں استعمال ہوگا؛ اسے GitHub فائل میں محفوظ نہیں کیا جائے گا۔
